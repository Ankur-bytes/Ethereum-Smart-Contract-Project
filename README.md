# Ethereum Smart Contract – Student Project Registry

## 🚀 Project Overview

This project demonstrates the creation and deployment of a simple Ethereum Smart Contract using Solidity.

The contract stores:
- Student Name
- Project Title
- Owner Address
- Deployment Timestamp

The contract was deployed and tested using Remix IDE.

---

## 🛠 Technologies Used
- Solidity ^0.8.0
- Ethereum Blockchain
- Remix IDE
